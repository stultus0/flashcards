# Italian Flashcards v1.0 — phone setup

## Send the file

Email **`flashcards_it.html`** to yourself as an attachment. It is a single ~170 KB file with 1,503 cards (Introduction and Chapters 1–40).

## iPhone / iPad

1. Open the email attachment.
2. Tap **Share** → **Save to Files**.
3. Choose **On My iPhone/iPad** → **Flashcards** (create the folder if needed) → **Save**.
4. Open the **Files** app, open **On My iPhone/iPad** → **Flashcards**, and tap `flashcards_it.html`.
5. Confirm that a card appears; tap it to reveal the answer, then choose a grade.

Launch it from **Files** whenever you study. iOS does not provide a dependable Home Screen web-app shortcut for a local HTML attachment. If the file opens as text or a static preview rather than interactive cards, the iPhone is blocking local HTML execution; use a hosted web link instead.

## Android

1. Open the email attachment and tap **Download**.
2. Open **Files by Google** (or your phone’s Files app) → **Downloads**.
3. Tap `italian-flashcards-v1.0.html` and choose **Chrome** if Android asks which app to use.
4. Confirm that a card appears; tap it to reveal the answer, then choose a grade.

Open the saved file from **Downloads** whenever you study. If Chrome shows source text, refuses to open the file, or does not retain progress, the phone/browser is blocking local HTML; use a hosted web link instead.

## Important

- Progress is saved separately on each phone/browser when that browser permits local storage. It does not sync.
- The 🔊 pronunciation button needs Internet access because it streams Italian audio.
- Do not use **Reset progress** unless you intend to erase that phone/browser’s schedule.

## Optional desktop shortcut

For a web-hosted copy: in **Chrome**, open the URL → **three-dot menu** → **Cast, save, and share** → **Create shortcut**. On a Mac in **Safari**, open the URL → **File** → **Add to Dock**.
